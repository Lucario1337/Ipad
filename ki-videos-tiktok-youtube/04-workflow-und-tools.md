# Workflow & Tools – ca. 1 Stunde pro Video

## Tools (Beispiele – die Tool-Landschaft ändert sich schnell)

| Aufgabe | Tool-Art | Kosten (grob) |
|---|---|---|
| Skript & Recherche | KI-Chat (z. B. Claude) + eigener Faktencheck | 0–20 €/Monat |
| Bilder | KI-Bildgenerator | 0–25 €/Monat |
| Bewegung (optional) | KI-Videogenerator (Bild → kurzer Clip) | 10–30 €/Monat |
| Stimme | Eigene Stimme (kostenlos, wirkt am echtesten) oder KI-Stimme | 0–20 €/Monat |
| Schnitt & Untertitel | CapCut (Vorlage, Auto-Untertitel) | 0–10 €/Monat |
| Musik | Nur die Musikbibliothek von TikTok bzw. YouTube | 0 € |

**Start-Budget:** 0–30 €/Monat. Erst bezahlen, wenn die ersten Videos laufen.

## Ablauf pro Video

| Schritt | Was | Zeit |
|---|---|---|
| 1 | Thema aus der Liste/Kommentaren wählen | 2 Min. |
| 2 | Skript schreiben lassen (Vorlage unten), **Fakten selbst prüfen** | 10 Min. |
| 3 | 8–12 Bilder generieren (Bild-Prompts aus dem Skript + Grund-Stil) | 15 Min. |
| 4 | Optional: 2–3 Bilder zu kurzen Clips animieren | 10 Min. |
| 5 | Voiceover aufnehmen (Handy, ruhiger Raum, Decke über dem Kopf hilft) | 5 Min. |
| 6 | In CapCut-Vorlage einsetzen: Bilder, leichter Zoom (Ken-Burns-Effekt), Untertitel, Zeit-Einblendungen, Musik leise | 15 Min. |
| 7 | 2× exportieren (TikTok + YouTube), hochladen, KI-Kennzeichnung setzen, planen | 5 Min. |

## Skript-Vorlage für den KI-Chat

```
Schreibe ein deutsches Voiceover-Skript, 160–190 Wörter, für ein
vertikales Video zum Thema: „Was wäre, wenn [THEMA]?"
Aufbau: 8 Abschnitte. Abschnitt 1 = Hook (max. 12 Wörter).
Dann eine Zeitleiste (sofort → Stunden → Jahre) oder eine Kette von Folgen.
Abschnitt 8 = Frage an die Zuschauer.
Nur wissenschaftlich belegte Aussagen; Spekulation als solche kennzeichnen.
Gib zu jedem Abschnitt einen englischen Bild-Prompt im Stil:
"cinematic, dramatic lighting, teal and orange color grade, vertical 9:16".
Keine echten Personen, keine Marken, keine bekannten Figuren.
```

## Batching (spart am meisten Zeit)

- **Sonntag:** 7 Skripte schreiben + prüfen (1,5 Std.)
- **Montag:** alle Bilder generieren (1,5 Std.)
- **Dienstag:** alle Voiceovers + Schnitt (3 Std.)
- **Dienstagabend:** alles in TikTok Studio und YouTube Studio planen (30 Min.)
- **Täglich:** 10 Min. Kommentare beantworten

→ ca. **7 Stunden pro Woche für 7 Videos**.

## Upload-Unterschiede

| | TikTok | YouTube Shorts |
|---|---|---|
| Länge | 61–90 s (muss > 60 s für Creator Rewards) | bis 3 Min. erlaubt |
| KI-Kennzeichnung | Schalter „KI-generierter Inhalt" | „Veränderte oder synthetische Inhalte: Ja" |
| Planung | TikTok Studio (Browser) | YouTube Studio |
| Wasserzeichen | Video **ohne** TikTok-Wasserzeichen zu YouTube hochladen (direkt aus CapCut exportieren) | – |
| Titel | Text-Overlay + Caption | Titel ≤ 60 Zeichen, `#shorts` |
| Uhrzeit | gleiche Uhrzeit oder YouTube 2 Std. später | |
